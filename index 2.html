What is this?

A table answering football’s most important unanswered question: what if hitting the post actually counted for something?

Matches are decided by each side’s woodwork hits. Ties are sorted by points, woodwork difference, woodwork for, then alphabetically.

Live match data comes from the open-source FPL Core Insights dataset.

Built for the glorious near miss. Data updates when the source dataset updates.
